# @paragraph-com/sdk

TypeScript SDK for the [Paragraph](https://paragraph.com) API. Used to interact with Paragraph posts, users, coins, & more.

## Install

```bash
yarn add @paragraph-com/sdk
```

## Quick start

```typescript
import { ParagraphAPI } from "@paragraph-com/sdk";

// For public endpoints
const api = new ParagraphAPI();
const post = await api.posts.get({ id: "postId" });

// For protected endpoints (creating posts, managing subscribers)
const apiWithAuth = new ParagraphAPI({ apiKey: "your-api-key" });
const newPost = await apiWithAuth.posts.create({
  title: "My Post",
  markdown: "# Hello World",
});
```

## Authenticated endpoints

Several endpoints require an API key, which identifies your publication. Pass it when creating the client:

```typescript
const api = new ParagraphAPI({ apiKey: "your-api-key" });

// Get your publication info
const publication = await api.me.get();

// List your drafts
const { items: drafts } = await api.posts.list({ status: "draft" });

// Update a post
await api.posts.update({
  id: "postId",
  title: "Updated Title",
  markdown: "## New content",
  status: "published",
});

// Delete a post
await api.posts.delete({ id: "postId" });
```

## Playbooks

A Playbook drafts a package of content (an article, social posts, and more) from a source like a GitHub repository. Set one up and run it from your own code, for example when a release ships:

```typescript
const api = new ParagraphAPI({ apiKey: "your-api-key" });

await api.playbooks.configure({
  key: "changelog",
  repository: "acme/widget",
  values: { audience: "Developers evaluating the SDK" },
});

const { runId } = await api.playbooks.startRun({
  key: "changelog",
  idempotencyKey: "release-2.4.0",
});

const run = await api.playbooks.getRun({ key: "changelog", runId });
```

A run creates drafts. Nothing is published until someone approves it in the Paragraph app. See [`examples/runPlaybook.ts`](examples/runPlaybook.ts) for polling a run to completion.
